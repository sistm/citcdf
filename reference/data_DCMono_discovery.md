# Gene expression matrix

Data used in the vignette of cit_gsa. The dataset contain normalized
single- cell RNA-seq gene expression from Dendritic Cells (DCs).

## Usage

``` r
data_DCMono_discovery
```

## Format

A data frame of numeric values with 7458 rows (genes) and 539 columns
(cells).

Row names are the genes symbol and column names are cells identifier.
