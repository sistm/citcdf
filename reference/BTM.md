# Gene set data base

Blood Transriptional Modules of Stanford.

## Usage

``` r
BTM
```

## Format

A list that contain 2 elements:

- genesets:

  A list where each element contain the genes of the gene set

- geneset.names:

  A character vector that contain the gene set names
