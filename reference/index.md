# Package index

## All functions

- [`X_perm()`](https://sistm.github.io/citcdf/reference/X_perm.md) :
  Compute the conditional permutations
- [`ccdf()`](https://sistm.github.io/citcdf/reference/ccdf.md) :
  Estimate the empirical conditional cumulative distribution function
- [`cit_asymp()`](https://sistm.github.io/citcdf/reference/cit_asymp.md)
  : Asymptotic test for conditional independence
- [`cit_gsa()`](https://sistm.github.io/citcdf/reference/cit_gsa.md) :
  Conditional independence test for gene set analysis
- [`cit_multi()`](https://sistm.github.io/citcdf/reference/cit_multi.md)
  : Multiple conditional independence testing
- [`cit_perm()`](https://sistm.github.io/citcdf/reference/cit_perm.md) :
  Permutation test for conditional independence
- [`perm_cont()`](https://sistm.github.io/citcdf/reference/perm_cont.md)
  : Permutation procedure when Z is continuous
- [`plot(`*`<cit_gsa>`*`)`](https://sistm.github.io/citcdf/reference/plot.cit_gsa.md)
  : Plot the conditional CDFs of every gene in a gene set
- [`plot(`*`<cit_multi>`*`)`](https://sistm.github.io/citcdf/reference/plot.cit_multi.md)
  : Plot of gene-wise p-values
- [`plot_compare_ccdf()`](https://sistm.github.io/citcdf/reference/plot_compare_ccdf.md)
  : Function to plot the CCDF according to the type of X and Z
