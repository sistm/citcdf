# DC subpopulation

DC subpopulation for each cells of the gene expression matrix.

## Usage

``` r
DCpop
```

## Format

A vector of character of length 539 that is the number of cells in the
expression matrix. The possible values are: DC1, DC2 & DC3 and pDC.
